---
title: Two new pages, and a tidier API tab
date: 2026-10-16
---

- Realtime: a page for Pusher channels and events. Subscribe, listen, whisper, and
  broadcast back — credentials come from the application itself, and the socket runs in
  the main process so nothing a channel sends can reach this window.
- Realtime: subscribe to every channel the application is currently using, found through
  Pusher's own list of occupied channels.
- HTTP: a page for the calls this application makes. Every one is listed as it finishes —
  from a request, a queued job, the scheduler or a command — with its status, where it
  came from, and curl's own timing as a timeline. Credentials are replaced before they
  leave PHP.
- API: filter a JSON response with a JSONPath expression, such as `$.data.*.id`.
- API: a response that is a page is rendered as one, in a sandbox where scripts and
  remote files do not run.
- API: saving a request says what it wrote and where, and the Save button marks a request
  that no longer matches its file.
- API: collections hold folders, nested as deep as you like, carried in the file as
  OpenAPI tags. A saved request can be moved or renamed from its own row, and removing
  one asks first.
- API: import an OpenAPI or Swagger document, or an Insomnia v5 collection, straight into
  a collection — folders and all.
- API: whoever you impersonate is remembered across requests and restarts; only the choice
  is kept, never the token.
- API: Cmd-R sends, the way Cmd-R runs a snippet in Tinker.
- ERD: export the diagram as SVG or PNG, save automatically, undo and redo with Cmd-Z,
  and type directly into a note on the canvas.
- ERD: the editor marks the line an error is on, Add sits on the canvas, and the tenant
  you picked is still picked next time.
- Settings is a page of its own, and this window — what's new — is a button above it.
- Every field in the app marks focus with its border instead of a glow, and the routes
  sidebar no longer shifts sideways when a scrollbar appears.
