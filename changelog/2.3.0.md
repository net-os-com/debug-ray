---
title: A menu bar icon
date: 2026-11-13
---

- A NetOS Debug icon in the menu bar, for glancing at what arrived while the window is
  out of sight. Click it for a panel with whether the receiver is listening and the latest
  stream events, newest first; click an event and the app opens on it. Right-click for
  Open, Settings… and Quit. Settings → Window → Show in menu bar takes it away again.
- The icon pulses when events arrive — once per burst, not once per payload, so a request
  that sends a hundred dumps does not set the menu bar blinking.
- A window closed and opened again, from the Dock, a banner or the menu bar, keeps its
  stream instead of starting empty.
- Cmd-K clears the stream for MCP clients too, so Claude Code reads what you see. Collected
  requests and outgoing calls stay, as they do in their own views.
- Collected requests and outgoing calls no longer push `ray()` events out of what MCP
  clients can read. The stream keeps a buffer of its own, the size set in Settings, where
  before one busy page load could crowd out every dump within minutes.
