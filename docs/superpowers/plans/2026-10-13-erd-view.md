# ERD View Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A canvas in NetOS Debug that draws the project's tables and their relations from the live MySQL schema, and writes a `schema.dbml` the repository can commit.

**Architecture:** `useSchema` already returns tables with columns, indexes and foreign keys per tenant. A pure mapper turns that into an `ErdModel`; one serialiser turns the model into DBML text and one arranger turns it into positions. The canvas is DOM cards on a `translate/scale` layer with a single SVG overlay beneath for the relation lines. Both files are written by the Laravel package through an artisan command, the same way saved API requests already are.

**Tech Stack:** Electron 44, React 19, TypeScript 7, electron-vite. Laravel 12 / PHP 8.4 for the package side. No new runtime dependencies.

**Spec:** `docs/superpowers/specs/2026-10-13-erd-view-design.md`

## Global Constraints

- **No test suite.** This project has none by standing decision, twice confirmed. Every task below verifies by running something and reading real output: pure functions through a throwaway probe under the session scratchpad, everything else in the running app. Do not add a test framework, a `tests/` directory, or a test script.
- **No new dependencies.** `@dbml/core` is deliberately out: nothing in this pass parses DBML. Writing it is hand-rolled.
- **The ERD never writes to the database and never writes migrations.** It reads.
- `schema.dbml` is output only. `schema.layout.json` is the one file read back.
- Verify with `npm run typecheck` and `npm run lint` before every commit; both must be silent.
- American English in code, comments and UI copy.
- Follow the existing file conventions: one responsibility per file, dependency injection, comments that explain why rather than what.

## Review Focus

Five things the spec implies that the happy path will not exercise, most likely to bite first:

1. **A composite primary key** — every column it covers must be marked `primary`, not just the first. Pinned in Task 1.
2. **A foreign key crossing databases** — must be flagged `crossDatabase` and drawn apart, because in MySQL it is not a real constraint. Pinned in Task 1.
3. **A circular foreign-key chain** — `users → teams → users` must not make auto-arrange loop forever or drop a table. Pinned in Task 3.
4. **An identifier DBML has to quote** — a table or column named after a reserved word, or containing a space or a dot, must come back out of dbdiagram.io unchanged. Pinned in Task 2.
5. **A layout out of step with the schema** — a stored position for a dropped table must be ignored, and a new table with no position must still be placed. Pinned in Task 3.

`src/renderer/src/erd/schema-to-model.ts`:

```ts
import type { SchemaIndex, SchemaKey, SchemaTable } from '../../../shared/tools'
import type { ErdColumn, ErdModel, ErdRelation, ErdTable } from './model'

/**
 * Turns the schema the Tools view already reads into the shape the canvas and
 * the serialiser consume.
 *
 * `primary` and `unique` come from the indexes rather than from the column
 * name, so a composite primary key marks every column it covers instead of
 * only the one that happens to be called `id`.
 */
export function schemaToModel(
  tables: SchemaTable[],
  database: string,
  centralDatabase: string,
): ErdModel {
  const known = new Set(tables.map((table) => table.name))

  return {
    tables: tables.map((table) => toTable(table, database)),
    relations: tables.flatMap((table) => toRelations(table, database, centralDatabase, known)),
  }
}

function toTable(table: SchemaTable, database: string): ErdTable {
  const primary = columnsIn(table.indexes, (index) => index.primary)
  const unique = columnsIn(table.indexes, (index) => index.unique && !index.primary)
  const references = new Map<string, { table: string; column: string }>()

  for (const key of table.keys) {
    key.columns.forEach((column, position) => {
      const foreign = key.foreignColumns[position]

      if (foreign !== undefined) {
        references.set(column, { table: key.table, column: foreign })
      }
    })
  }

  return {
    name: table.name,
    database,
    columns: table.columns.map(
      (column): ErdColumn => ({
        name: column.name,
        type: column.type,
        nullable: column.nullable,
        primary: primary.has(column.name),
        unique: unique.has(column.name),
        references: references.get(column.name) ?? null,
      }),
    ),
    indexes: table.indexes
      .filter((index) => !index.primary)
      .map((index) => ({ name: index.name, columns: index.columns, unique: index.unique })),
  }
}

function columnsIn(indexes: SchemaIndex[], match: (index: SchemaIndex) => boolean): Set<string> {
  return new Set(indexes.filter(match).flatMap((index) => index.columns))
}

/**
 * A foreign key whose target is not among the tables we read points at the
 * central database: tenants live in their own, and some keys reach across.
 * MySQL does not enforce those, so they are flagged rather than drawn as if
 * they were real constraints.
 */
function toRelations(
  table: SchemaTable,
  database: string,
  centralDatabase: string,
  known: Set<string>,
): ErdRelation[] {
  return table.keys.flatMap((key: SchemaKey) =>
    key.columns.flatMap((column, position): ErdRelation[] => {
      const foreign = key.foreignColumns[position]

      if (foreign === undefined) {
        return []
      }

      return [
        {
          from: { table: table.name, column },
          to: { table: key.table, column: foreign },
          onDelete: key.onDelete,
          crossDatabase: !known.has(key.table) && database !== centralDatabase,
        },
      ]
    }),
  )
}
```

```ts
import type { ErdColumn, ErdModel, ErdTable } from './model'

/** DBML keywords and anything not a bare identifier have to be quoted. */
const BARE = /^[A-Za-z_][A-Za-z0-9_]*$/
const RESERVED = new Set(['table', 'ref', 'enum', 'indexes', 'note', 'project', 'as', 'default'])

/**
 * Renders the model as DBML.
 *
 * Written by hand rather than through `@dbml/core`: this pass only ever writes,
 * and the official package carries a full parser and a set of exporters we
 * would not use. When a later pass needs to read a committed file back, that is
 * the moment to take the dependency.
 */
export function toDbml(model: ErdModel): string {
  const blocks = model.tables.map((table) => tableBlock(table))
  const refs = model.relations.map(
    (relation) =>
      `Ref: ${quote(relation.from.table)}.${quote(relation.from.column)} > ` +
      `${quote(relation.to.table)}.${quote(relation.to.column)}` +
      (relation.onDelete ? ` [delete: ${relation.onDelete}]` : ''),
  )

  return [...blocks, ...refs].join('\n\n') + '\n'
}

function tableBlock(table: ErdTable): string {
  const lines = table.columns.map((column) => `  ${columnLine(column)}`)

  if (table.indexes.length > 0) {
    lines.push('', '  indexes {')

    for (const index of table.indexes) {
      const columns = index.columns.map(quote).join(', ')
      const settings = index.unique ? ' [unique]' : ''

      lines.push(`    (${columns})${settings}`)
    }

    lines.push('  }')
  }

  return `Table ${quote(table.name)} {\n${lines.join('\n')}\n}`
}

function columnLine(column: ErdColumn): string {
  const settings: string[] = []

  if (column.primary) {
    settings.push('pk')
  }

  if (column.unique) {
    settings.push('unique')
  }

  settings.push(column.nullable ? 'null' : 'not null')

  return `${quote(column.name)} ${column.type} [${settings.join(', ')}]`
}

/**
 * dbdiagram.io accepts a double-quoted identifier anywhere a bare one is
 * allowed, so anything that is not plainly bare is quoted rather than guessed
 * at. A name carrying a quote of its own is escaped.
 */
function quote(name: string): string {
  if (BARE.test(name) && !RESERVED.has(name.toLowerCase())) {
    return name
  }

  return `"${name.replace(/"/g, '\\"')}"`
}
```

- [ ] **Step 1: Write the arranger**

```ts
import type { ErdModel } from './model'

export type Point = { x: number; y: number }
export type Layout = Record<string, Point>

const CARD_WIDTH = 240
const COLUMN_GAP = 96
const ROW_GAP = 48
/** Vertical pitch between cards — not the height of a row inside one. */
const CARD_PITCH = 320
const PER_LAYER = 4

/**
 * Places every table, keeping any position already stored.
 *
 * Layered by relation depth: tables that reference nothing come first, then
 * each layer holds the tables whose references are all already placed. The
 * result is the same every run, which a force-directed layout is not — and on a
 * schema this size, "it moved and I cannot tell why" is a thing you would have
 * to debug.
 */
export function arrange(model: ErdModel, stored: Layout): Layout {
  const placed: Layout = {}
  const names = model.tables.map((table) => table.name)
  const present = new Set(names)

  // A stored position for a table that no longer exists is dropped rather than
  // carried, so a removed table cannot corrupt the file.
  for (const name of names) {
    const position = stored[name]

    if (position) {
      placed[name] = position
    }
  }

  const remaining = names.filter((name) => !(name in placed))

  if (remaining.length === 0) {
    return placed
  }

  for (const [index, name] of layered(model, remaining, present).entries()) {
    const layer = Math.floor(index / PER_LAYER)
    const row = index % PER_LAYER

    placed[name] = {
      x: layer * (CARD_WIDTH + COLUMN_GAP),
      y: row * (CARD_PITCH + ROW_GAP),
    }
  }

  return placed
}

/**
 * Orders the unplaced tables so a table follows the ones it references.
 *
 * A cycle — `users` references `teams` which references `users` — would leave
 * both waiting on the other forever, so once a pass places nothing the rest are
 * emitted in name order and the loop ends.
 */
function layered(model: ErdModel, remaining: string[], present: Set<string>): string[] {
  const targets = new Map<string, Set<string>>()

  for (const name of remaining) {
    targets.set(name, new Set())
  }

  for (const relation of model.relations) {
    const from = targets.get(relation.from.table)

    if (from && present.has(relation.to.table) && relation.to.table !== relation.from.table) {
      from.add(relation.to.table)
    }
  }

  const ordered: string[] = []
  const done = new Set<string>()
  let pending = [...remaining].sort()

  while (pending.length > 0) {
    const ready = pending.filter((name) =>
      [...(targets.get(name) ?? [])].every((target) => done.has(target) || !pending.includes(target)),
    )

    if (ready.length === 0) {
      ordered.push(...pending)
      break
    }

    for (const name of ready) {
      ordered.push(name)
      done.add(name)
    }

    pending = pending.filter((name) => !done.has(name))
  }

  return ordered
}
```

- [ ] **Step 1: Write the store**

```php
<?php

declare(strict_types=1);

namespace NetOs\Debug\Erd;

/**
 * Owns where a project keeps its schema diagram.
 *
 * The path lives here rather than in the desktop app for the same reason the
 * collections path does: the app knows about diagrams, the package knows where
 * this repository keeps things, and the file has to land inside the bind mount
 * that git is watching.
 */
class ErdStore
{
    public function __construct(private readonly string $directory)
    {
    }

    public function schemaFile(): string
    {
        return $this->directory.'/schema.dbml';
    }

    public function layoutFile(): string
    {
        return $this->directory.'/schema.layout.json';
    }

    /**
     * Both files are written together so the two can never describe different
     * schemas.
     *
     * @param  array<string, mixed>  $layout
     * @return list<string>
     */
    public function save(string $dbml, array $layout): array
    {
        if (! is_dir($this->directory)) {
            mkdir($this->directory, 0o755, true);
        }

        file_put_contents($this->schemaFile(), $dbml);
        file_put_contents(
            $this->layoutFile(),
            json_encode(
                ['tables' => $layout, 'savedAt' => date(DATE_ATOM)],
                JSON_PRETTY_PRINT | JSON_UNESCAPED_SLASHES
            )."\n"
        );

        return [$this->schemaFile(), $this->layoutFile()];
    }

    /**
     * @return array{layout: array<string, mixed>, savedAt: string|null}
     */
    public function read(): array
    {
        $raw = is_file($this->layoutFile()) ? file_get_contents($this->layoutFile()) : false;
        $decoded = $raw === false ? null : json_decode($raw, true);

        if (! is_array($decoded)) {
            return ['layout' => [], 'savedAt' => null];
        }

        return [
            'layout' => is_array($decoded['tables'] ?? null) ? $decoded['tables'] : [],
            'savedAt' => is_string($decoded['savedAt'] ?? null) ? $decoded['savedAt'] : null,
        ];
    }
}
```

```php
 * anything that can reach the API, while a command is reachable by whoever can
 * already run code in the container.
 */
class ErdCommand extends Command
{
    protected $signature = 'netos-debug:erd {action : save or read}';

    protected $description = 'Read and write the schema diagram in this repository';

    public function handle(ErdStore $store): int
    {
        return match ((string) $this->argument('action')) {
            'read' => $this->say($store->read()),
            'save' => $this->save($store),
            default => $this->refuse('Use save or read.'),
        };
    }

    private function save(ErdStore $store): int
    {
        $payload = json_decode((string) file_get_contents('php://stdin'), true);

        if (! is_array($payload) || ! is_string($payload['dbml'] ?? null)) {
            return $this->refuse('Expected {"dbml": string, "layout": object} on stdin.');
        }

        $layout = is_array($payload['layout'] ?? null) ? $payload['layout'] : [];

        return $this->say(['files' => $store->save($payload['dbml'], $layout)]);
    }

    /**
     * @param  array<string, mixed>  $data
     */
    private function say(array $data): int
    {
        $this->line((string) json_encode($data + ['error' => null], JSON_UNESCAPED_SLASHES));

        return self::SUCCESS;
    }

    private function refuse(string $message): int
    {
        $this->line((string) json_encode(['error' => $message]));

        return self::FAILURE;
    }
}
```

```ts
import type { ErdSaved, ErdStored } from '../../shared/erd'
import { runDocker } from '../exec/run-docker'

const ERD_TIMEOUT_MS = 30_000

/**
 * Talks to the Laravel package, which owns the files. Same reasoning as
 * collections: the path is configuration in the application rather than an
 * assumption compiled into this app, and the file lands in the bind mount.
 */
async function run(
  containerId: string,
  workingDir: string,
  action: string,
  input: string | null = null,
): Promise<Record<string, unknown>> {
  const result = await runDocker(
    ['exec', '-i', '-w', workingDir, containerId, 'php', 'artisan', 'netos-debug:erd', action],
    input,
    ERD_TIMEOUT_MS,
  )

  try {
    return JSON.parse(result.stdout.trim()) as Record<string, unknown>
  } catch {
    return { error: result.stderr.trim() || 'The command returned nothing readable.' }
  }
}

export async function readErd(containerId: string, workingDir: string): Promise<ErdStored> {
  const data = await run(containerId, workingDir, 'read')

  return {
    layout: (data.layout as ErdStored['layout']) ?? {},
    savedAt: (data.savedAt as string | null) ?? null,
    error: (data.error as string | null) ?? null,
  }
}

export async function saveErd(
  containerId: string,
  workingDir: string,
  dbml: string,
  layout: ErdStored['layout'],
): Promise<ErdSaved> {
  const data = await run(containerId, workingDir, 'save', JSON.stringify({ dbml, layout }))

  return {
    files: (data.files as string[]) ?? [],
    error: (data.error as string | null) ?? null,
  }
}
```

- [ ] **Step 1: Write the table card**

Card width must match `CARD_WIDTH` in `arrange.ts` (240) or the arrangement will overlap. Columns show name, type, and a `pk` / `unique` / `null` marker; the header shows the table name and, when it differs from the central database, the database it came from.

```tsx
import type { ErdTable } from './model'
import type { Point } from './arrange'

type TableCardProps = {
  table: ErdTable
  at: Point
  selected: boolean
  onSelect: () => void
  onMove: (point: Point) => void
}

export function TableCard({ table, at, selected, onSelect, onMove }: TableCardProps) {
  return (
    <div
      className={selected ? 'erd-card erd-card--selected' : 'erd-card'}
      data-table={table.name}
      onPointerDown={(event) => {
        event.stopPropagation()
        onSelect()

        const start = { x: event.clientX, y: event.clientY }
        const origin = { ...at }
        const move = (moved: PointerEvent): void =>
          onMove({
            x: origin.x + (moved.clientX - start.x),
            y: origin.y + (moved.clientY - start.y),
          })
        const up = (): void => {
          window.removeEventListener('pointermove', move)
          window.removeEventListener('pointerup', up)
        }

        window.addEventListener('pointermove', move)
        window.addEventListener('pointerup', up)
      }}
      style={{ transform: `translate(${at.x}px, ${at.y}px)` }}
    >
      <div className="erd-card__head">
        <span className="erd-card__name">{table.name}</span>
      </div>
      {table.columns.map((column) => (
        <div className="erd-card__row" key={column.name}>
          <span className="erd-card__col">{column.name}</span>
          <span className="erd-card__type">{column.type}</span>
          {column.primary ? <span className="erd-card__mark">pk</span> : null}
        </div>
      ))}
    </div>
  )
}
```

The drag listeners go on `window` rather than the card, because a fast drag leaves the card behind and a listener bound to it would stop receiving moves.

- [ ] **Step 2: Write the relations layer**

```tsx
import type { Layout } from './arrange'
import type { ErdRelation } from './model'

const CARD_WIDTH = 240
/** Where a row sits inside the card, near enough for a line to read right. */
const HEADER = 34

type RelationsLayerProps = {
  relations: ErdRelation[]
  layout: Layout
  rowOf: (table: string, column: string) => number
}

/**
 * One SVG for every line, sized 1x1 with overflow visible: the paths draw well
 * outside its box, and because it takes no pointer events it never swallows a
 * click meant for a card sitting over it.
 */
export function RelationsLayer({ relations, layout, rowOf }: RelationsLayerProps) {
  return (
    <svg className="erd-lines" height="1" width="1">
      {relations.map((relation, index) => {
        const from = layout[relation.from.table]
        const to = layout[relation.to.table]

        if (!from || !to) {
          return null
        }

        const x1 = from.x + CARD_WIDTH
        const y1 = from.y + HEADER + rowOf(relation.from.table, relation.from.column)
        const x2 = to.x
        const y2 = to.y + HEADER + rowOf(relation.to.table, relation.to.column)
        const bend = Math.max(40, Math.abs(x2 - x1) / 2)

        return (
          <path
            className={relation.crossDatabase ? 'erd-line erd-line--cross' : 'erd-line'}
            d={`M ${x1} ${y1} C ${x1 + bend} ${y1}, ${x2 - bend} ${y2}, ${x2} ${y2}`}
            key={`${relation.from.table}.${relation.from.column}-${index}`}
          />
        )
      })}
    </svg>
  )
}
```

- [ ] **Step 3: Write the canvas**

The canvas owns pan and zoom and renders the layer. Pan is a drag on the background; zoom is the wheel, clamped between 0.2 and 2. `fit` is exported so the toolbar in Task 7 can call it: it takes the bounding box of every placed card plus the viewport size and returns `{ x, y, z }`.

```tsx
import { useRef, useState, type ReactNode } from 'react'
import type { Layout, Point } from './arrange'
import type { ErdModel } from './model'
import { RelationsLayer } from './relations-layer'
import { TableCard } from './table-card'

/** One column row inside a card; the relation layer anchors on the same value. */
const COLUMN_ROW_HEIGHT = 22
const MIN_ZOOM = 0.2
const MAX_ZOOM = 2

export type View = { x: number; y: number; z: number }

export function fitView(model: ErdModel, layout: Layout, width: number, height: number): View {
  const points = model.tables.map((table) => layout[table.name]).filter((point): point is Point => !!point)

  if (points.length === 0 || width === 0 || height === 0) {
    return { x: 0, y: 0, z: 1 }
  }

  const left = Math.min(...points.map((point) => point.x))
  const top = Math.min(...points.map((point) => point.y))
  const right = Math.max(...points.map((point) => point.x)) + 240
  const bottom = Math.max(...points.map((point) => point.y)) + 320
  const z = Math.min(MAX_ZOOM, Math.max(MIN_ZOOM, Math.min(width / (right - left), height / (bottom - top)) * 0.9))

  return { x: (width - (right - left) * z) / 2 - left * z, y: (height - (bottom - top) * z) / 2 - top * z, z }
}
```

```tsx
type ErdCanvasProps = {
  model: ErdModel
  layout: Layout
  view: View
  selected: string | null
  onView: (view: View) => void
  onSelect: (table: string | null) => void
  onMove: (table: string, at: Point) => void
}

export function ErdCanvas({ model, layout, view, selected, onView, onSelect, onMove }: ErdCanvasProps) {
  const rowOf = (table: string, column: string): number => {
    const found = model.tables.find((one) => one.name === table)
    const index = found?.columns.findIndex((one) => one.name === column) ?? -1

    return (index < 0 ? 0 : index) * COLUMN_ROW_HEIGHT
  }

  return (
    <div
      className="erd-canvas"
      onPointerDown={(event) => {
        if (event.button !== 0) {
          return
        }

        onSelect(null)

        const start = { x: event.clientX, y: event.clientY }
        const origin = { x: view.x, y: view.y }
        const move = (moved: PointerEvent): void =>
          onView({ ...view, x: origin.x + (moved.clientX - start.x), y: origin.y + (moved.clientY - start.y) })
        const up = (): void => {
          window.removeEventListener('pointermove', move)
          window.removeEventListener('pointerup', up)
        }

        window.addEventListener('pointermove', move)
        window.addEventListener('pointerup', up)
      }}
      onWheel={(event) => {
        const next = Math.min(MAX_ZOOM, Math.max(MIN_ZOOM, view.z * (event.deltaY < 0 ? 1.1 : 1 / 1.1)))

        onView({ ...view, z: next })
      }}
    >
      <div
        className="erd-layer"
        style={{ transform: `translate(${view.x}px, ${view.y}px) scale(${view.z})` }}
      >
        <RelationsLayer layout={layout} relations={model.relations} rowOf={rowOf} />
        {model.tables.map((table) => {
          const at = layout[table.name]

          return at ? (
            <TableCard
              at={at}
              key={table.name}
              onMove={(point) => onMove(table.name, point)}
              onSelect={() => onSelect(table.name)}
              selected={selected === table.name}
              table={table}
            />
          ) : null
        })}
      </div>
    </div>
  )
}
```

The zoom is applied around the layer's origin rather than the cursor. That is the simpler behaviour and it is what `Fit` exists for; anchoring zoom to the pointer is a refinement, not a requirement of this pass.

- [ ] **Step 1: Write the hook**

```ts
import { useCallback, useEffect, useMemo, useState } from 'react'
import type { TinkerContainer } from '../../../shared/tinker'
import type { SchemaTable } from '../../../shared/tools'
import { arrange, type Layout, type Point } from './arrange'
import { toDbml } from './dbml'
import { schemaToModel } from './schema-to-model'
import type { View } from './erd-canvas'

const WORKING_DIR = '/var/www/html'

export function useErd(container: TinkerContainer | null, tables: SchemaTable[], tenant: string) {
  const [layout, setLayout] = useState<Layout>({})
  const [view, setView] = useState<View>({ x: 0, y: 0, z: 1 })
  const [selected, setSelected] = useState<string | null>(null)
  const [saved, setSaved] = useState<string[]>([])
  const [error, setError] = useState<string | null>(null)

  const model = useMemo(
    () => schemaToModel(tables, tenant || 'central', 'central'),
    [tables, tenant],
  )

  // The stored layout belongs to the repository, so it is read once per
  // container rather than per schema load.
  useEffect(() => {
    if (container === null) {
      return
    }

    let cancelled = false

    void window.ray.readErd(container.id, WORKING_DIR).then((stored) => {
      if (!cancelled) {
        setLayout(stored.layout)
        setError(stored.error)
      }
    })

    return () => {
      cancelled = true
    }
  }, [container])

  // Re-arranging keeps every position it already has, so a new table appears
  // without the rest of the diagram jumping.
  useEffect(() => {
    setLayout((current) => arrange(model, current))
  }, [model])

  const save = useCallback(async (): Promise<void> => {
    if (container === null) {
      return
    }

    const result = await window.ray.saveErd(container.id, WORKING_DIR, toDbml(model), layout)

    setSaved(result.files)
    setError(result.error)
  }, [container, model, layout])

  return {
    model,
    layout,
    view,
    setView,
    selected,
    setSelected,
    saved,
    error,
    save,
    move: useCallback((table: string, at: Point) => {
      setLayout((current) => ({ ...current, [table]: at }))
    }, []),
    rearrange: useCallback(() => setLayout(arrange(model, {})), [model]),
  }
}
```

`rearrange` passes an empty stored layout on purpose: "Auto-arrange" means discard what is there and lay it out again, which is what the button says.
